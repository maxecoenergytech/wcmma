## How publishing works (so you know what happens to a worksheet)

```
You fill a worksheet (5–15 min)
   → volunteer/agent copies it into a website data file
   → automatic build check (catches typos/errors before anything publishes)
   → you approve a one-line preview ("Announcement published, expires 31 Dec")
   → live on wcmaaindia.com within a minute of push
```

Turnaround commitments: **Announcements ≤24 h · News ≤1 week of an event · Dojo updates ≤1 week · Everything else ≤2 weeks.** If a worksheet goes quiet past its SLA, ask for a status.

## Data protection reminders for worksheets

1. Apply the **minimum-necessary** rule: only what will be published.
2. Students: short-form names + grade + validity only (portal standard already in force).
3. No dates of birth, blood groups, addresses, or private numbers — for anyone.
4. Photos of minors only with the consent column completed.
5. Worksheets sent by WhatsApp are still personal data — send only to the official secretariat number +91 78969 62207 / email wingchun91@gmail.com, and delete superseded copies.
